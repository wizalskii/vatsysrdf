VATSYS RDF PLUGIN v1.0.0 - INSTALLATION INSTRUCTIONS

===================================================================
WHAT IS THIS?
===================================================================
Radio Direction Finder (RDF) plugin for VATSYS that highlights
aircraft based on VATSIM network data correlation.

FEATURES:
- Automatically highlights aircraft on your frequencies
- Works with both VHF and HF frequencies
- Uses VATSIM public data for accurate correlation
- Visual indicators via custom labels
- No external dependencies needed!

===================================================================
INSTALLATION
===================================================================

1. COPY FILES:
   Copy these files to your VATSYS Plugins folder:
   - VatsysRDF.dll
   - Newtonsoft.Json.dll

   Plugins folder location:
   Documents\vatSys Files\[YourProfile]\Plugins\

   (Create the Plugins folder if it doesn't exist)

2. (OPTIONAL) LABEL INDICATOR:
   - Copy Labels.xml to your profile folder
   - Edit your aircraft label templates in VATSYS
   - Add "RDF_TX" to see circle indicators (○ or ●)

3. RESTART VATSYS:
   Close and reopen VATSYS for the plugin to load

===================================================================
HOW IT WORKS
===================================================================

The plugin automatically:
1. Fetches VATSIM network data every 15 seconds
2. Identifies which aircraft are on your frequencies
3. Highlights those aircraft with visual indicators
4. Updates every second for real-time correlation

VISUAL INDICATORS:
- Label Item: Circle indicator (○ or ●) if RDF_TX is configured
- Future: Track colors (to be enabled in next version)

===================================================================
CONFIGURATION
===================================================================

Edit RDFSettings.json to customize:
- Enabled: Turn plugin on/off
- SingleTxColor: Color for highlighting (#FFFFFF = white)
- ConcurrentTxColor: Color for multiple aircraft (#FF0000 = red)

===================================================================
TROUBLESHOOTING
===================================================================

Plugin not loading?
1. Check DLL is in correct Plugins folder
2. Make sure Newtonsoft.Json.dll is also copied
3. Restart VATSYS
4. Use DebugView to see plugin messages

No indicators showing?
1. Ensure plugin is Enabled in RDFSettings.json
2. Connect to VATSIM network
3. Check that aircraft are actually on your frequencies
4. Allow 15 seconds for VATSIM data to load
